> **QueryMind** is an enterprise-grade, full-stack Generative AI conversational platform. It combines real-time Server-Sent Events (SSE) typewriter streaming, sliding-window conversation memory management, anti-hallucination prompt engineering, and JWT authentication with an inclusive, high-contrast, WCAG 2.0-compliant dark glassmorphism interface.

---

## 🚀 Key Highlights & Architectural Features

* **Real-Time SSE Typewriter Streaming**: Provides ultra-low perceived latency responses using Server-Sent Events (SSE), delivering streaming tokens dynamically as generated by Google Gemini models (`gemini-3.8-flash`, `gemini-2.5-flash`, `gemini-1.5-flash`).
* **Sliding Window Context & Memory Management**: Employs an intelligent token-budgeted memory service in JavaScript (`MemoryService`) that preserves conversation history across turns while pruning older exchanges to prevent token overflow.
* **Anti-Hallucination & Grounding Directives**: Injects strict operational guidelines and role-based personas (*Software Architect, General Assistant, Creative Thinker, Fact-Checking Analyst*) to enforce citation discipline and reduce hallucinations.
* **Dual-Tier Security & Rate Limiting**: Protects backend resources using `express-rate-limit` with general route rate limits (100 req/15 min) and specialized AI inference limiters (30 prompts/min).
* **Robust Dual-Mode Database Architecture**: Supports standard **MongoDB / Mongoose** for persistent cloud storage, paired with an automatic **In-Memory Store fallback** that enables instant local execution with zero database installation required.
* **WCAG 2.0 Accessible UI**: Engineered with high-contrast color ratios, semantic HTML landmarks, full keyboard navigation (Enter to send, Shift+Enter for newline, Escape to close modals), and custom dark glassmorphic styling without heavy external CSS frameworks.
* **1-Click Reviewer Demo Access**: Allows recruiters and reviewers to test the entire application, authentication, and chat flows instantly without registering credentials.

## ⚡ Quick Start Guide (Run Locally)

### 1. Prerequisites
- **Node.js**: v18.x or newer (Tested on Node v24)
- **npm**: v9.x or newer

### 2. Configure Environment Variables
Inside `backend/.env` (already pre-configured with safe defaults):
```env
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:5173
MONGODB_URI=mongodb://127.0.0.1:27017/querymind
JWT_SECRET=querymind_secret_jwt_key_987654321_ankita_2026

# Optional: Add your live key from https://aistudio.google.com/app/apikey
# If left empty, QueryMind runs in interactive Demo Mode automatically!
GEMINI_API_KEY=
```

### 3. Start the Backend Server
```bash
cd backend
npm run dev
```
*The backend starts at `http://localhost:5000` with healthcheck at `http://localhost:5000/api/health`.*

### 4. Start the Frontend Application (in a new terminal)
```bash
cd frontend
npm run dev
```
*The frontend starts at `http://localhost:5173`.*

## 🌐 Deployment Guide (When You're Ready to Deploy)

> **Important**: Do not share your live API keys or database passwords publicly in git commits.

### A. Deploy Backend (Render, Railway, or Fly.io)
1. Push your repository to GitHub.
2. Link your repo to **Render** or **Railway** as a Web Service.
3. Set **Root Directory** to `backend`.
4. Set **Build Command** to: `npm install`
5. Set **Start Command** to: `npm start`
6. Add your Environment Variables:
   - `NODE_ENV`: `production`
   - `PORT`: `5000` (or leave default for Railway/Render)
   - `CLIENT_URL`: `https://your-frontend-domain.vercel.app`
   - `MONGODB_URI`: `mongodb+srv://<user>:<password>@cluster0.mongodb.net/querymind`
   - `JWT_SECRET`: A secure 32+ character random secret
   - `GEMINI_API_KEY`: Your live Google AI Studio API key

### B. Deploy Frontend (Vercel or Netlify)
1. Import your GitHub repository into **Vercel**.
2. Set **Root Directory** to `frontend`.
3. Set **Framework Preset** to `Vite`.
4. Add Environment Variable:
   - `VITE_API_URL`: `https://your-backend-api.onrender.com/api`
5. Click **Deploy**.
